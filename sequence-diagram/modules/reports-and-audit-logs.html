Module 06 · Sequence A

MYDO Staff Multi-Dimensional Analytics & Streamed CSV Export

Shows how Staff query municipal youth distribution, scholarship statistics, event turnout, and cash incentive disbursements by Barangay, Program, and Year, and export streamed CSV files.

StaffReportController@index StaffReportController@data StaffReportController@export StaffReportService 
sequenceDiagram
    autonumber
    actor Staff as MYDO Staff Officer
    participant RepUI as Staff Reports Page
    participant RepCtrl as StaffReportController
    participant RepSvc as StaffReportService
    participant DB as MySQL (youth_profiles, barangays, scholarships, activities, incentives)

    Staff->>RepUI: Open /staff/reports
    RepUI->>RepCtrl: GET /staff/reports (initial filters)
    RepCtrl->>RepSvc: getReportsData(filters)
    RepSvc->>DB: Aggregate Youth per Barangay, Scholarship approvals, Event attendance & Cash disbursements
    DB-->>RepSvc: Return structured summary KPIs & tabular datasets
    RepSvc-->>RepUI: Render charts & breakdown tables

    Staff->>RepUI: Change Year or Program filter
    RepUI->>RepCtrl: GET /staff/reports/data?program_id=...&year=...
    RepCtrl->>RepSvc: getReportsData(filters)
    RepSvc-->>RepUI: Return updated JSON analytics without full page reload

    Staff->>RepUI: Click Export CSV (select report type: barangay / scholarships / incentives / events)
    RepUI->>RepCtrl: GET /staff/reports/export?type=...&year=...
    RepCtrl->>RepSvc: exportCsv(filters, type)
    RepSvc->>DB: Query filtered records for selected report type
    RepSvc-->>Staff: Return StreamedResponse (text/csv attachment download)
Module 06 · Sequence B

Centralized ActivityLogger Capture & Admin Audit Trail Inspection

Illustrates how sensitive Staff and Admin mutations write structured records (with actor role, IP, user agent, and before/after JSON snapshots) to activity_logs, and how Administrators audit them.

ActivityLogger::log ActivityAttendanceService::removeAttendanceWithAudit AdminActivityLogController 
sequenceDiagram
    autonumber
    actor Actor as Staff / Admin Actor
    participant Controllers as Domain Controllers & Services
    participant Logger as ActivityLogger / ActivityLog Model
    participant DB as MySQL (activity_logs)
    actor Admin as System Administrator
    participant LogUI as Admin Activity Logs Page

    Note over Actor, DB: 1. Immutable Audit Capture on Sensitive Mutations
    Actor->>Controllers: Execute mutation (Approve/Reject Youth or Scholar, Register SK, Create/Delete Event, Remove Attendance, Record Release, Change Password)
    Controllers->>Logger: Record action, description, subject_type, subject_id, old_values, new_values, metadata
    Logger->>DB: Insert append-only ActivityLog (actor_name, actor_role, ip_address, user_agent, created_at)

    Note over Admin, LogUI: 2. Executive Audit Trail Search & Payload Inspection
    Admin->>LogUI: Open /admin/activity-logs (loads total_logs, logs_today, availableRoles, availableActions)
    Admin->>LogUI: Filter by Actor Role (admin | staff), Action type, Date range, or Keyword
    LogUI->>DB: GET /admin/get-activity-logs (AdminActivityLogController@getData)
    DB-->>LogUI: Return paginated ActivityLog entries
    Admin->>LogUI: Click View Details on a specific audit row
    LogUI->>DB: GET /admin/activity-logs/{id} (AdminActivityLogController@show)
    DB-->>LogUI: Return full old_values, new_values, metadata, IP & user_agent JSON
