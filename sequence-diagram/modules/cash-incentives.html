Module 05 · Sequence A

Program Budgeting, Snapshot Nomination & Beneficiary Review

Shows how Staff or Administrators create a Cash Incentive Program, filter eligible youth, capture a historical academic/barangay snapshot upon selection, and review nominations.

Staff / AdminCashIncentiveProgramController Staff / AdminCashIncentiveBeneficiaryController ProgramManagementService 
sequenceDiagram
    autonumber
    actor Officer as MYDO Staff / Admin
    participant ProgUI as Cash Incentives UI
    participant ProgCtrl as CashIncentiveProgramController
    participant BenCtrl as CashIncentiveBeneficiaryController
    participant DB as MySQL (programs, beneficiaries, status_histories)

    Officer->>ProgUI: Create Cash Incentive Program (Title, Funding Year, Per-Beneficiary Amount, Budget)
    ProgUI->>ProgCtrl: POST /cash-incentives
    ProgCtrl->>DB: Generate CIP-YYYY-XXXX code, insert Program & write ActivityLog
    ProgCtrl-->>ProgUI: Redirect to Program Show Page

    Officer->>ProgUI: Open Add Beneficiaries Modal & filter by Barangay / Year Level / Search
    ProgUI->>BenCtrl: GET /cash-incentives/{program}/eligible-youth
    BenCtrl->>DB: Query active approved YouthProfiles not yet nominated in this program
    BenCtrl-->>ProgUI: Return eligible youth candidates

    Officer->>ProgUI: Select youth IDs & confirm nomination
    ProgUI->>BenCtrl: POST /cash-incentives/{program}/beneficiaries/select
    BenCtrl->>DB: Snapshot school_name, program, year, brgyCode into CashIncentiveBeneficiary (status=pending)
    BenCtrl->>DB: Insert CashIncentiveStatusHistory & ActivityLog
    BenCtrl-->>ProgUI: Refresh beneficiary roster & quota counters

    Officer->>ProgUI: Review nominated beneficiary (Approve or Reject with remarks)
    ProgUI->>BenCtrl: POST /cash-incentives/{program}/beneficiaries/{beneficiary}/review
    BenCtrl->>DB: Validate max_beneficiaries / budget cap, update status & append StatusHistory
    BenCtrl-->>ProgUI: Update approved beneficiary count & budget utilization bar
Module 05 · Sequence B

Individual / Batch Cash Release, Reversion, Reports & Youth Ledger

Covers payout disbursement recording (single or batch), administrative release reversion, printable/CSV beneficiary reports, and read-only verification in the Youth Portal.

Staff / AdminCashIncentiveReleaseController Staff / AdminCashIncentiveReportController YouthCashIncentiveController 
sequenceDiagram
    autonumber
    actor Officer as MYDO Staff / Admin
    participant RelCtrl as CashIncentiveReleaseController
    participant RepCtrl as CashIncentiveReportController
    participant DB as MySQL (releases, beneficiaries, activity_logs)
    actor Youth as Youth Beneficiary

    Note over Officer, DB: 1. Individual or Batch Payout Recording
    Officer->>RelCtrl: POST /releases/{beneficiary}/record OR POST /releases/batch
    RelCtrl->>DB: Verify beneficiary status == approved & remaining program budget
    RelCtrl->>DB: Create/Update CashIncentiveRelease (status=released, ack_number, released_at, released_by)
    RelCtrl->>DB: Record CashIncentiveStatusHistory & ActivityLog
    RelCtrl-->>Officer: Return updated released amount & remaining budget

    opt Revert Accidental Release
        Officer->>RelCtrl: POST /releases/{beneficiary}/revert (reason)
        RelCtrl->>DB: Revert release status, log audit reason & restore program balance
    end

    Note over Officer, DB: 2. Financial Summary & CSV / Individual Voucher Export
    Officer->>RepCtrl: GET /reports/summary, /reports/export-csv, or /beneficiaries/{id}/report
    RepCtrl->>DB: Aggregate program totals, barangay breakdown & payout records
    RepCtrl-->>Officer: Render printable voucher/summary or stream CSV download

    Note over Youth, DB: 3. Youth Portal Read-Only Cash Incentives Ledger
    Youth->>DB: GET /youth/cash-incentives (YouthCashIncentiveController@index)
    DB-->>Youth: Return personal grant history, funding year filter, payout status & ACK number
