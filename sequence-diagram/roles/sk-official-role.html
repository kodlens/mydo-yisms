SK Official — Role Sequence Diagrams

Documents how registered Sangguniang Kabataan (SK) Officials authenticate with their assigned Barangay & SK Position, monitor barangay-level youth counts, and submit photo & narrative evidence for municipal activities.

Model: App\Models\User (role = sk) Assigned Jurisdiction: sk_position + brgyCode Evidence Model: SkActivityEvidence

SK Flow 01

Portal Sign-In & Barangay-Scoped SK Dashboard

After MYDO Staff or an Administrator registers an SK Official with their Barangay jurisdiction, logging in routes them to /sk/dashboard with metrics scoped to their assigned Barangay.

AuthenticatedSessionController HandleInertiaRequests SkDashboardController@index 
sequenceDiagram
    autonumber
    actor SK as SK Official
    participant UI as Portal Login & SK UI
    participant Auth as Auth & Role Middleware
    participant Dash as SkDashboardController
    participant DB as MySQL (users, barangays, youth_profiles)

    Note over SK, DB: Phase 1 - Authentication & Role Redirection
    SK->>UI: Enter username & password on /login
    UI->>Auth: POST /login
    Auth->>DB: Authenticate User (role = sk) on web guard
    Auth-->>UI: Redirect via User::dashboardRoute() to /sk/dashboard

    Note over SK, DB: Phase 2 - Barangay Context & Scoped Metrics
    UI->>Auth: GET /sk/dashboard (EnsureUserHasRole: sk)
    Auth->>DB: HandleInertiaRequests loads barangay, city, province on auth.user
    Auth->>Dash: Invoke SkDashboardController@index
    Dash->>DB: Load User with barangay, city, province & read brgyCode
    Dash->>DB: Count approved Youth & SK Officials in assigned brgyCode
    Dash->>DB: Fetch SK Official's recent SkActivityEvidence & upcoming published Activities
    DB-->>Dash: Return barangay stats, active AcademicYear & evidence history
    Dash-->>UI: Render SK Dashboard with SK Position & Brgy. Name badge
SK Flow 02

Uploading & Managing Event Photo and Narrative Evidence

SK Officials document barangay participation in published municipal events by uploading verified photos (1–10 images) and an official narrative report, which immediately becomes visible to MYDO Staff and Administrators.

SkEventActivityController@index SkEventActivityController@storeEvidence SkEventActivityController@destroyEvidence 
sequenceDiagram
    autonumber
    actor SK as SK Official
    participant UI as SK Events & Evidence Page
    participant Temp as UploadFileController
    participant Ctrl as SkEventActivityController
    participant Disk as Public Storage Disk
    participant DB as MySQL (sk_activity_evidences)
    actor Reviewers as MYDO Staff & Admin

    Note over SK, DB: Phase 1 - Browse Published Events & Stage Photos
    SK->>UI: Open /sk/events-activities
    UI->>Ctrl: GET /sk/events-activities
    Ctrl->>DB: Fetch published Activities + this SK Official's my_evidences
    Ctrl-->>UI: Render event cards & existing submission history
    SK->>UI: Select 1 to 10 event pictures (PNG/JPG/JPEG)
    UI->>Temp: POST /temp-upload for each selected image
    Temp->>Disk: Save staged image in storage/app/public/temp
    Temp-->>UI: Return temporary filename

    Note over SK, Reviewers: Phase 2 - Submit Narrative & Commit Evidence
    SK->>UI: Enter Event Narrative Description & click Submit Evidence
    UI->>Ctrl: POST /sk/events-activities/{activity}/evidence
    Ctrl->>Disk: Validate MIME types & move files to upfiles/sk-evidences/activity-{id}/sk-{user_id}
    Ctrl->>DB: Insert SkActivityEvidence (activity_id, user_id, description, photos JSON)
    Ctrl-->>UI: Return 200 OK with public photo URLs
    Reviewers->>DB: Open SK Evidence Modal in Staff or Admin Events Directory
    DB-->>Reviewers: Display photos + narrative tagged with SK Position & Brgy. Name

    opt Delete Own Evidence Submission
        SK->>UI: Click Delete on own evidence entry
        UI->>Ctrl: DELETE /sk/events-activities/{activity}/evidence/{evidence}
        Ctrl->>Disk: Delete stored evidence image files
        Ctrl->>DB: Delete SkActivityEvidence row (verified by owner user_id)
        Ctrl-->>UI: Return deletion confirmation
    end
